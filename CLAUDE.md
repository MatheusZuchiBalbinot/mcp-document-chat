# MCP Document Chat

Code for Anthropic Academy's Introduction to MCP course, built on its starter `cli_project`.

- **One commit per lesson.** Each lesson's code, tests and README update (tick its box in "Course progress") go in a
  single commit. Lessons without code (e.g. the server inspector) get no commit.
- Commit subjects follow `~/.claude/CLAUDE.md` (Conventional Commits, English, subject only, no attribution trailer).
- Verify with `uv run pytest` before committing.
